If you're wondering what this repository is for:
* It's mostly a personal project where I practice writing simple or advanced specifications to figure out how rules are laid out.
* I usually do this for fun, so I'm not obligated to keep writing the original specifications, but I like to challenge myself.
* I may make unconventional choices when designing specifications, like giving "optional" and "not restricted" two different definitions.
* Although there are still improvements that are yet to be made, it's your choice if you want to implement them or not.
* Everyone has the choice to point out flaws like:
  * Contradictions
  * Or unspecified edge cases,
and:
  * Inconsistent,
  * Vague
  * Or erroneous text
of my personal specifications.
* You can also fork this repository if you want to build off of the specifications. You don't have to ask for permission. However, **you must not claim that a fork is the original repository.**
